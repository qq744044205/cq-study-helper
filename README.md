# 重庆培训网学习助手（开源播放版）

独立编写的浏览器用户脚本，使用 MIT 许可证。支持读取培训项目、阶段、课程与章节，勾选课程并在本地保存队列，也会尝试播放当前页面中可访问的 HTML5 视频。

## 安装和使用

1. 安装 Tampermonkey 或 Violentmonkey，新建脚本，复制 `cq-study-helper.user.js` 的全部内容并保存。更新时请替换原脚本，避免同时启用多个副本。
2. 在 `https://cqrl.21tb.com/` 登录后，使用悬浮框选择培训项目和阶段，勾选课程；切换“章节预览”读取所选课程的章节及记录。可点击“刷新”重新读取项目。
3. 勾选课程后点击“打开所选课程”，或打开课程播放页面点击“开始播放”。如浏览器阻止自动播放，请手动点击视频。播放结束后请在平台选择下一章节并核对学习状态。

## 限制

- 课程和章节来自平台接口，可能随平台变化；目前仅在 `cqrl.21tb.com` 读取课程，另一域名上会提示先进入该平台。项目列表依赖登录账号返回的学习路径，未实现原脚本的完整目录分类和旧式课程章节回退。
- 视频结束后，脚本尝试读取平台课程进度；当平台确认当前课程完成时，尝试打开队列中的下一门。视频结束后，脚本尝试点击平台显示的“下一节”按钮；它不会后台提交学习进度。
- 只能访问当前页面或同源 iframe 中的 HTML5 视频；跨域 iframe、特殊播放器和验证弹窗可能影响功能。
- 未在实际登录课程页面测试；视频结束不代表平台确认完成，请在平台核对进度。
- 不发送数据到第三方；开关和队列保存在网站的 localStorage，请遵守平台使用规则。

检测到部分平台异常提示时，脚本停止自动播放、暂停可访问视频并设置 1 倍速；处理提示后需手动继续。异常检测依赖页面提示文字和结构，无法保证识别所有提示，跨域页面可能无法访问。
